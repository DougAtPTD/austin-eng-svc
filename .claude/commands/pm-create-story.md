Create a new story on the agent board using the `board_create_story` tool.

Structure the story as follows:

**Title**: $ARGUMENTS

**Description**: Write a clear problem statement and user-facing summary.

**Technical Spec**: Include:
- Files likely to be modified
- Approach and design considerations
- Dependencies or prerequisites
- Edge cases to handle

**Acceptance Criteria**: Write as a markdown checklist:
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] ...

After creating the story, use `board_transition_story` to move it to `todo` if it's ready for development.
